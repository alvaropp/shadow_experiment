Why?

Each bulb lights the floor with its own colour. The hand blocks some bulbs at each spot. The spot gets the sum of the bulbs that are not blocked.
  • Block blue: red + green = yellow
  • Block red: green + blue = cyan
  • Block green: red + blue = magenta
  • Two shadows overlap: only the third colour stays
  • All three blocked (umbra): black
Edges are soft because each bulb has a size. Part of a bulb can be hidden (penumbra).
