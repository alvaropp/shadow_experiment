# Coloured shadows

A small web app that shows why a hand under red, green and blue lamps casts yellow, magenta and cyan shadows.

Each bulb is a small area light. For each floor point, the page adds the light from the bulbs that the hand does not block. The sums use linear RGB.

Open `index.html` in a browser, or see the GitHub Pages site for this repository. Drag the hand to move it.
